# 这里需要你补截图

截图是 IzzyOnDroid 收录的硬性要求（至少要能看出应用的界面），
但我没有真机，不能替你生成——假截图比没有截图更糟。

请安装 debug APK 后按顺序截 4 张，放进本目录：

| 文件名 | 内容 |
| --- | --- |
| `1-home.png` | 首页：总开关打开、学习时段 20:00–22:00、提醒节奏 |
| `2-category.png` | 分类页：已勾选若干应用，三种状态都可见 |
| `3-card.png` | 提醒卡片出现在小红书/抖音之上（这是最有说服力的一张） |
| `4-stats.png` | 本地记录页 |

规格：
* 竖屏，最短边 ≥ 320px，推荐 1080×2400 左右的原生分辨率
* PNG，不要加设备边框、不要加水印
* 系统语言建议中文（zh-CN），英文目录另截一套或留空

截图命令：

```bash
adb exec-out screencap -p > 1-home.png
```
